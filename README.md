# Скрипт для включения/выключения активного микрофона (Linux)

Поддреживаемая звуковая подсистема: **ALSA**<br>
Звуковые оповещения: **Discord**<br>
*(для касомизации замените файлы mute.wav и unmute.wav)*

### Установка

Выполните эти команды по порядку:

- git clone https://github.com/rtxdiv/alsamic
- ./alsamic/install
- rm -rf ./alsamic
